Jira Issue Panel

Displays coverage meter, tabbed verdict cards (Missing Risk, Found, Needs Context, Out of Scope), deletion badges, and Markdown export.

SURFACE 03
Workflow Gate

SURFACE 04
Rovo Agent

Syntactic Citation Verification

Every LLM-proposed file path, snippet, and 1-based line number is validated against raw unified diff hunks (+[L<num>] / -[L<num>]). Hallucinated references are stripped automatically.

Enterprise Isolation & Least Privilege

Per-user KVS snapshots isolate Bitbucket 3LO OAuth tokens across reviewers, while the manifest requests only 3 read/storage scopes with zero Jira or Confluence write scopes.

Deterministic lockfile filtering, chunk budgeting, Promise.allSettled batch isolation, and an 18-second runtime guard keep multi-file PR audits inside Forge's 25-second FaaS limit.
